# 區域網路與 PWA 設定指南

本文件說明如何讓其他裝置（如 iPad、手機）透過區域網路連線至 StallEasy POS，以及如何設定 PWA 以獲得全螢幕原生 App 的體驗。

## 1. 區域網路連線 (iPad/平板)

系統已實作自動 API 網址判斷機制，您只需將伺服器 IP 提供給裝置即可。

### 步驟：
1. **確認電腦 IP**：在執行伺服器的電腦上開啟終端機，輸入 `ipconfig` 找到 IPv4 位址（例如：`192.168.1.100`）。
2. **啟動連線版本**：請使用 `.\scripts\windows\start-dev.bat` 啟動，或在 Linux 執行 `./scripts/linux/start-dev.sh`；兩者預設都綁定在 `0.0.0.0`。
3. **平板開啟網頁**：在 iPad 的 Safari 瀏覽器中輸入 `http://[電腦IP]:3000`。
    - 系統會自動將 API 請求導向至 `http://[電腦IP]:8000/api/v1`。

## 2. PWA 全螢幕模式設定 (iOS)

為了獲得像 App 一樣的體驗（隱藏瀏覽器網址列、全螢幕操作），請按照以下步驟操作：

### 設定步驟：
1. **開啟 Safari**：在 iPad 瀏覽器中開啟 POS 登入頁面。
2. **分享選單**：點擊網址列旁的「分享」圖示（向上箭頭）。
3. **加入主畫面**：選單向下捲動，點擊「**加入主畫面**」(Add to Home Screen)。
4. **確認名稱**：確認名稱為 "StallEasy POS"，點擊「新增」。
5. **啟動 App**：回到 iPad 主畫面，點擊新的圖示啟動。

### 優勢：
- **隱藏 UI**：自動隱藏 iOS Safari 的網址列與功能列。
- **防止縮放**：已鎖定視窗邊界，防止連按兩次放大。
- **自訂圖示**：已優化圖示背景，在 iOS 桌面上不會出現異常白邊。

## 3. 圖示與樣式相關說明
- **Logo 檔案路徑**：`frontend/src/app/icon.png` (由 Next.js 自動處理 favicon)。
