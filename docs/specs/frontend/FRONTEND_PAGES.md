# 前端頁面結構規劃 (Frontend Page Structure)

**文件版本**: v1.0  
**對應設計**: Minimalist Zen  
**框架**: Next.js App Router

---

## 1. 頁面總覽 (Sitemap)

我們將應用程式分為兩大區域：**前台作業 (POS)** 與 **後台管理 (Backoffice)**。

- **/ (Root)**: 登入頁 / 啟動頁
- **/pos**: 收銀主介面
  - **/pos/checkout**: 結帳流程 (Modal/Panel)
  - **/pos/orders**: 今日訂單 / 退款作廢
  - **/pos/closing**: 日結作業 (Z-Report)
- **/admin**: 後台管理 (Owner Only)
  - **/admin/dashboard**: 營收儀表板
  - **/admin/products**: 商品管理
  - **/admin/settings**: 系統設定 (印表機、稅務、使用者)

---

## 2. 詳細頁面功能

### 2.1 啟動與登入 (Auth)
- **路徑**: `/login`
- **功能**:
  - 店鋪代碼輸入 (多店版預留)
  - **PIN Code 快速登入**: 巨大的數字鍵盤，供店員快速換班登入。
  - 狀態顯示: 資料庫連線狀態、離線模式提示。

### 2.2 收銀主機 (POS Main)
- **路徑**: `/pos`
- **佈局**: 
  - **左側 (Menu)**: 商品分類 (Tabs) + 商品網格 (Grid)。Minimalist Zen 風格，強調圖片與文字的清晰度。
  - **右側 (Cart)**: 購物車清單、折扣選擇、會員搜尋。
  - **底部 (Action)**: 「結帳」大按鈕 (Gold)、掛單、更多功能。
- **關鍵交互**: 點擊商品即加入購物車，長按商品可編輯 (加辣/特製)。

### 2.3 結帳流程 (Checkout)
- **路徑**: `/pos` (Overlay Modal)
- **功能**:
  - **支付方式選擇**: 現金 (預設)、LINE Pay、外送平台。
  - **數字鍵盤**: 輸入實收金額，即時計算找零。
  - **發票選項**: 輸入統編、手機載具 (2026 合規重點)。
  - **完成頁**: 顯示找零大字，自動列印收據。

### 2.4 訂單與交易 (Transactions)
- **路徑**: `/pos/orders`
- **功能**:
  - 列表顯示今日所有交易。
  - **稅務安心功能**: 
    - **作廢 (Void)**: 需輸入管理員密碼，並記錄原因。
    - **更正 (Adjustment)**: 僅能新增更正單，不可修改原單。
    - **補印收據**。

### 2.5 日結作業 (Closing)
- **路徑**: `/pos/closing`
- **功能**:
  - **錢箱盤點**: 輸入實際現金。
  - **短溢計算**: 系統自動比對 理論值 vs 實際值。
  - **報表預覽**: 顯示今日營收、分類銷售佔比。
  - **執行日結**: 鎖定今日帳務，產出 Z-Report PDF 並上傳備份。

### 2.6 後台管理 (Admin - Lite)
*初期版本可先做簡單版，或直接整合在 POS 設定中*
- **商品管理**: 上下架、修改價格、庫存設定。
- **硬體設定**: 設定出單機 IP、掃描槍測試。

## 3. 頁面動線與權限 (Navigation & RBAC)

### 3.1 核心動線
- **登入後** → 直接進入 `/pos` (收銀主畫面)，不經過 Dashboard。
- **後台入口**: 在 `/pos` 介面中設置「管理」按鈕 (入口)，點擊後驗證權限進入 `/admin` 或彈出管理面板。

### 3.2 功能預留
- **分單付款 (Split Bill)**: 架構上預留欄位與 UI 擴充空間 (Feature Flag OFF)。

### 3.3 角色權限規則 (RBAC) - **必須實作**
所有路由與敏感操作需經過雙重驗證 (Middleware + Server Action)。

| 角色 | 進入 /pos | 作廢訂單 (Void) | 日結 (Closing) | 進入 /admin | 備註 |
|---|---|---|---|---|---|
| **Staff** | ✅ | ❌ | ❌ | ❌ | 僅能點餐收銀 |
| **Manager** | ✅ | ✅ | ✅ | ❌ | 店務管理 (日結/退款) |
| **Owner** | ✅ | ✅ | ✅ | ✅ | 全權 (含系統設定) |

### 3.4 技術實作要求
1.  **Middleware**: `middleware.ts` 進行 Route Guard，攔截未授權存取。
2.  **Server Components**: 在 Page/Action 層級再次驗證 `session.role`，防止直接呼叫 API 繞過。
