# 進階財務報表系統規格書 (Advanced Financial Reporting Spec)

本文件定義了 StallEasy POS 系統進階財務報表的功能需求與數據結構。

## 一、基本資訊（Report Header）
- **門店名稱**：顯示當前報表所屬的店鋪名稱。
- **報表期間**：支援每日、每週、每月及自訂日期範圍過濾。
- **幣別**：顯示金額單位 (目前預設 TWD)。
- **產出時間**：報表生成的精確時間 (YYYY-MM-DD HH:mm:ss)。
- **資料版本**：用於稽核與避免改帳爭議 (可使用與時間戳相關的 Ref Code)。

## 二、營收總覽（Revenue Summary）
**核心 KPI 區塊**，提供快速的營運概況：
- **總營業額 (Gross Revenue)**：所有銷售項目的總金額。
- **折扣金額**：促銷活動或手動折讓的金額總計。
- **退款金額**：已退款或作廢訂單的金額。
- **淨營收 (Net Revenue)**：`總營業額 - 折扣 - 退款`。
- **訂單數**：有效成交的訂單總筆數。
- **客單價 (AOV)**：`淨營收 / 成交訂單數`。
- **稅額**：營業稅額估算 (若適用)。

## 三、銷售結構分析（Sales Breakdown）
### 1. 商品分類營收占比
針對每個商品分類 (如：飲料、主食、加料) 統計：
- **銷售額**
- **銷售數量**
- **營收占比 (%)**

### 2. 熱銷商品排行 (Top Products)
列出銷售表現最佳的商品：
- **商品名稱**
- **銷售數量**
- **銷售金額**
- **毛利** (進階功能，需扣除成本)

### 3. 時段營收分析 (Hourly Analysis)
**排班參考依據**：
- **每小時營收**
- **每小時訂單數**
- **尖峰時段標記**

## 四、成本與毛利（Profitability）
針對經營成效的深度分析 (需配合商品成本設定)：
- **食材成本 (COGS)**：依據 BOM 表計算的理論成本。
- **包材成本**：外帶或特定商品使用的包材成本。
- **毛利分析**：
  - **毛利** = `淨營收 - 商品成本`
  - **毛利率** = `毛利 / 淨營收`

## 五、支付方式分析（Payment Breakdown）
統計各種支付管道的表現：
- **現金**
- **信用卡**
- **行動支付** (LINE Pay 等)
- **第三方外送平台** (UberEats / Foodpanda)

**每種方式需顯示**：
- 營收金額
- 占比 (%)
- 手續費估算 (若參數已設定)
- 實收金額

## 六、退款與異常（Exception & Refund）
防弊與異常監控：
- **退款筆數**
- **退款原因分析**
- **取消訂單紀錄**
- **改單紀錄**

## 七、庫存影響（Inventory Impact）— 進階
- **原料消耗量**：依據銷售商品理論扣庫存量。
- **理論庫存 vs 實際庫存**：(需配合盤點功能)。
- **損耗率**。

## 八、營運效率指標（Operational KPI）
- **平均出餐時間** (若有 KDS 整合)。
- **每小時產能**。
- **人均產值** (Total Revenue / 出勤人數)。

## 九、趨勢比較（Trend Comparison）
- **本期 vs 上期成長率** (WoW, MoM)。
- **同比成長** (YoY)。
- **成長曲線圖**。

## 十、現金對帳（Cash Reconciliation）
針對收銀機現金流的稽核：
- **開班現金 (Opening Cash)**：班次開始時的現金。
- **班中收款 (Cash Sales)**：班次內的現金銷售額。
- **現金收支變動**：中途補錢/取款紀錄。
- **班結現金 (Closing Cash)**：實際清點金額。
- **現金短溢 (Shortage/Overage)**：`班結現金 - (開班 + 銷售 + 補錢 - 取款)`。
